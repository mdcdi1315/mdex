

### Retrieve Spawn Data for a specific player.

Like the `Get Data For All Players` command, this command only reads the Player Logical Data for a specific player given by the specified argument.

Command Syntax:

~~~
/mdex teleporter_spawn_data get_for_player <player>
~~~

| Argument          | Meaning                                                                                                                                                                                                                                                                                                   |
|--------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `player`            | The player to execute the command upon. Must be a player logged in to the server for this to succeed.                                                                                                                                       |

> [!NOTE]
This command will fail if the specified player has not used the Teleporting Manager before.
