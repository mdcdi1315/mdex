### Teleporting commands.

This document provides the high-level teleporting commands
that are authored by server administrators to teleport players
to/from the Mining Dimension and can be useful on servers that 
execute commands.

Those commands can be accessed by accessing the sub-command `teleporting_manager`:

~~~
/mdex teleporting_manager
~~~

| Command                                                                                           |
|-------------------------------------------------------------------------------|
| [Teleport Player](TeleportPlayerUsingTeleportingManager.md) |
| [Evacuate All Players To Dimension](EvacuateAllPlayersTo.md)  |
